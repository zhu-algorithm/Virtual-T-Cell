# Multimodal dataset schema v1

The training interface is deliberately portable: one directory contains
`manifest.json` plus `arrays.npz`. It can be produced from MuData/AnnData,
10x outputs, or another ETL pipeline without making those libraries mandatory
at inference time.

## Manifest

`manifest.json` must include:

- `schema_version`: `virtual-t-cell.multimodal.v1`
- `dataset_name`: stable human-readable identifier
- `data_origin`: `real`, `simulated`, or `mixed`
- `paired_measurements`: whether modalities refer to the same cells
- `modalities`: source and normalization notes for each matrix

For real data, also record accessions, genome build, feature identifiers,
normalization, licenses, and preprocessing software. `data_origin=mixed` must
describe which arrays are real and which are generated. Never label imputed or
simulated values as measurements.

## Arrays

Every array lives in `arrays.npz`; strings must be NumPy Unicode arrays (not
pickled objects).

| Key | Shape | Meaning |
| --- | --- | --- |
| `obs__cell_id` | cells | globally unique observation ID |
| `obs__donor_id` | cells | donor or synthetic-donor ID |
| `obs__batch` | cells | experimental batch |
| `obs__cell_type` | cells | T-cell subtype/annotation |
| `obs__condition` | cells | stimulation/context label |
| `obs__time_hours` | cells | continuous time after perturbation |
| `obs__perturbation` | cells | HGNC target or `CTRL` |
| `obs__perturbation_strength` | cells | 0–1 nominal strength |
| `obs__is_control` | cells | control flag |
| `obs__split` | cells | `train`, `validation`, or `test` |
| `X__<modality>` | cells × features | numeric matrix |
| `var__<modality>` | features | feature names |
| `mask__<modality>` | cells | whether the row was measured |

Supported modality names are `rna`, `atac`, `protein`, and `tcr`. RNA features
should be HGNC symbols/Ensembl IDs; ATAC features should include genome-build
coordinates; protein features should be antibody target IDs; TCR features are
fixed numeric sequence/repertoire features. Raw CDR3, V/J and clonotype tables
may be retained beside this interchange format but are not generated by the
model.

Missing modalities are zero-filled only for storage and must have a false mask.
The mask, not the numeric value, determines whether a measurement exists.

## Leakage control

Assign splits by donor (and preferably perturbation) before fitting. The bundled
simulator uses row-level splits only because it is an executable toy fixture;
it is not an evaluation protocol for real data.
